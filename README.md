# Radikalt bokmål for språkmodeller

Dette repoet er en språkveileder for å få språkmodeller til å skrive **konsekvent radikalt bokmål** uten å gli over i nynorsk, dialekt eller blandingsspråk. Den kan brukes med KI-chatter m.m.

## Start her

Instruksjonene ligger i fila [RADIKALT_BOKMAL.md](RADIKALT_BOKMAL.md). Den enkleste måten å bruke den på, er så skrive inn noe som dette i en KI-chat:

```
Skriv på radikalt bokmål som forklart på https://raw.githubusercontent.com/hcholm/kiradbm/refs/heads/main/RADIKALT_BOKMAL.md . Hold deg konsekvent til det som står der, og ikke gli over i nynorsk, dialekt eller blandingsspråk.
```

Du kan også legge den inn som oppstartsinstruks i en KI-chat.

For ChatGPT: Legg instruksen over inn på Settings / Personalization / Custom instruction.

For Claude AI: Legg instruksen over inn på Settings / General / Custom instructions.

Du kan også laste ned fila, redigere den og bruke den som en mal for å lage dine egne instruksjoner. Merk at forskjellige KI-modeller vil oppfatte og følge instruksjoner på litt forskjellige måter. Som alltid med KI, er det ikke garantert at den følger instruksjonene perfekt.
